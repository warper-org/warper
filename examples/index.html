Features

Built for Performance

Every optimization matters. Advanced techniques deliver smooth scrolling with any dataset size.

Rust + WebAssembly

Core calculations run in compiled WebAssembly for near-native performance on range calculations and binary search.

O(1) Index Lookups

Fenwick trees enable constant-time offset calculations. No more O(n) scans on every scroll event.

Zero GC Pressure

Pre-allocated memory pools eliminate garbage collection during scroll for consistent 120+ FPS.

Variable Heights

Full support for dynamic item sizes with Fenwick tree recalculations in O(log n) time.

GPU Accelerated

CSS transform3d and contain: strict for hardware-accelerated compositing on the GPU.

Cross-Browser

Full support for Chrome, Firefox, Safari, and Edge. Works on mobile browsers too.
